## Prepper Emergency Power Sizing

### Level 1: Essential Backup (500W)

Power: Phone charging, LED lights, radio, small fridge

- **Generator:** DIY bifilar pancake coil (100–200W)

## Prepper-Specific Tips

1. **Start with Level 1** — Build the essential system first, expand later
2. **Store spare bearings** — Critical replacement part
3. **Keep tools organized** — Generator maintenance requires basic tools
4. **Learn to wind coils** — Spare coils can be wound on-site
5. **Document wiring** — Label everything; future-you will thank you
6. **Practice regularly** — Run the system monthly to keep batteries healthy
