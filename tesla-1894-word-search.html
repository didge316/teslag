Tesla 1894 Word Search: Free Energy 0, Perpetual 0

The 1894 File · a linkable data page. Every count on it comes from a command, and the command is printed on the page.

Published: October 28, 2026  |  Updated: October 28, 2026

Standfirst. This series says the 1894 book never uses the phrase 'free energy'. That is a countable claim, so it should be checkable without taking this site's word for anything. This page is the working: the text that was searched, the command that searched it, the counts, the printed page of every hit, and the one place where two honest runs of the same command return different totals.

The argument built on these numbers is on Tesla on Free Energy: What He Actually Said. This page is the data behind that argument, and it draws no conclusion of its own. It exists so that a number quoted anywhere in The 1894 File can be traced to a command and a page.

The Text Layer and the Offset Rule

The volume is Martin (ed.), The Inventions, Researches and Writings of Nikola Tesla, with Special Reference to His Work in Polyphase Currents and High Potential Lighting, D. Van Nostrand, New York, 1894. Our copy is a scan of the archive.org item inventionsresear00martiala: 518 page images, numbered page-001 to page-518, with a text layer. That text layer is extracted to one file,

books/extracted/tesla-1894-plain.txt, split into 506 page bodies, each marked with the scan file number it came from.

The scan file numbers and the book's own page numbers are not the same thing, and the difference is measured rather than guessed. Printed page = scan file number minus 18. You can check that without our files: open scan 447 of the item and the page you get is the one the book numbers 429, with 429 printed in its own corner.

The offset was checked across the volume. 402 body pages carry a bare page number in the text layer, and 367 of those numbers equal the scan file number minus 18. The other 35 are misreads by the text layer rather than disagreements about pagination: scan 226 is printed p. 208 and the layer reads its folio as '308'; scan 446 is printed p. 428 and the layer reads '438'. Chapter opening pages carry no folio at all, which is exactly what the offset rule is for. Scan 442 is printed p. 424, it opens chapter XXXVI, and the only number on it is the chapter numeral.

The Command, Verbatim

Two runs against one file, transcribed as they came out on 2026-10-20:

python3 books/tools/count_terms.py \
  'free energy' free-energy 'free energ' perpetual perpetu 'over unity' over-unity \
  unity free energy generator magnetic 'magnetic generator' pyro-magnetic \
  thermo-magnetic magneto dynamo radiometer inexhaustible

python3 books/tools/count_terms.py --keep-furniture 'magnetic generator'

The script prints its own conditions in the first three lines of its output: the command it was run with, the file it read, whether running heads were kept or dropped, and the offset rule. A number taken from that output carries its provenance with it.

What the script does to the text before counting, which is the part that decides whether a hit is found at all, is the same folding the quote checker in this repository uses:

  • ligatures folded, so the print's 'fi' ligature reads as 'fi'
  • the long-s read as 's', and the OCR artefact that sets '8' for 'S' reversed
  • curly quotes, dashes and ellipses replaced by their plain forms
  • a hyphen at a line end removed along with the line break, so a word broken across two lines reads

as one word

  • a hyphen inside a compound removed between letters, so 'pyro-magnetic' and 'pyromagnetic' are the

same string to the search. Letters only: a numeric range like 400-500 is left alone

  • whitespace collapsed, everything lower case

Two counting rules are reported separately, because they answer different questions:

  • whole word: the term stands alone, with a non-word character on each side
  • substring: the term appears anywhere, including inside a longer word or compound

And two indexes, because the same text gives different totals depending on what is searched:

  • prose only, the default: running heads, bare page numbers and short all-capital display lines

are dropped before searching, so a chapter title is not in the text being counted

  • everything kept, with --keep-furniture: the page text as it sits in the file

Two rows in that table start with a scan file number instead of a page number, and they do it because there is no page number to give. Scan 17 is the volume's own table of contents: it sets the chapter titles in display type, and it is where the seventh 'pyro-magnetic' and the fifth 'thermo-magnetic' occurrence sit. Front matter carries no printed folio, so the script reports that hit at printed page -1, which is its way of saying 'no folio here, cite the scan file'. The default index drops those display lines, which is exactly why those two rows lose two occurrences each between the prose-only and everything-kept columns.

The first seven rows are the claim. The rest are controls, and a null result without controls is worth very little. The same command on the same file finds 9 standalone occurrences of 'unity', 4 of 'radiometer' and 1 of 'inexhaustible'. A zero from this method means the string is not there, not that the method is blind.

The two rows that matter most for anyone who has read the marketing are 'free' and 'energy', four rows above 'free energy'. The book uses 'free' 97 times and 'energy' 243 times and never puts them next to each other.

The Five Occurrences, Read in Context

A count of five invites one question, which is: five of what. The answer changes what the number means, so it is in the body rather than in a footnote.

The sequence 'magnetic generator' never stands alone in this volume. Its whole-word count is 0 in both indexes. Every one of its substring occurrences sits inside a longer word: the print sets 'pyro-magnetic generator' in display type and in the preface, and 'pyromagnetic generator' closed up in running text and in the index. What the search finds is the machine chapter XXXVI is about.

Two of the five are prose. One is a chapter title, one is a preface list, one is an index entry. That is worth saying plainly, because 'the book mentions magnetic generators five times' reads differently once you know that two of the five are the book filing its own text.

The preface sentence is the volume's editors describing what the volume contains: it includes "a great many other inventions in arc lighting, transformers, pyro-magnetic generators, thermo-magnetic motors" (1894, p. 6). That is not Tesla writing.

Neither are the two prose occurrences. They are the compiler's, and the chapter says at its opening where the information came from: "In an interview with Mr. Tesla on this subject, the compiler learned of an experiment which will interest students" (1894, p. 424). The two occurrences are his summary of that subject. The first is "Mr. Tesla has also devoted his attention to the development of a pyromagnetic generator of electricity" (1894, p. 429), and the second, later in the same passage, is "the enlargement of these ideas will be found in Mr. Tesla's work on the pyromagnetic generator, treated in this chapter" (1894, p. 429).

The first of those two stops before a superscript footnote marker. The text layer puts the marker inside the word, as 'electricity1', so a quotation that ran on would be quoting something the print separates.

The chapter title is named here rather than quoted as one string, because the text layer does not hold it as one string. It reads the line in four fragments: 'CHAPTEK', 'THERMO-MAGNETIC', 'XXXVI.' and 'MOTORS AND PYRO-MAGNETIC GENERATORS.' The heading as the book sets it is on the crop below, and it is legible there.

The reading gives one thing the counts table cannot show: the book is not consistent about the hyphen. The preface on printed p. 6 and the chapter title on printed p. 424 set 'pyro-magnetic' with a hyphen. The running text on printed p. 429, twice, and the index entry on printed p. 496 set 'pyromagnetic' closed up. The two crops below are the print itself rather than the text layer, and between them they show both forms.

That inconsistency is why the search folds hyphens at all. Counted over the raw text layer with no normalisation, 'pyro-magnetic' returns 3 hits and 'pyromagnetic' returns 4, seven in all. A reader typing either spelling into a plain search finds fewer than half of them.

Why One Run Says Four and the Other Says Five

The default index cleans each page before searching it, because in this scan running heads sit in the middle of sentences. The rule that does it is short enough to print:

if re.fullmatch(r"[ivxlcdmIVXLCDM]{1,5}|\d{1,4}", s):
    continue                    # a bare page number
...
if (len(s) < 140 and nwords <= 9 and ratio > 0.7) or \
   (len(s) < 60 and nwords <= 6 and ratio > 0.6):
    continue                    # a running head, or a display line

ratio is the share of capital letters in the line and nwords its word count. Run over scan 442, printed p. 424, that rule removes four lines:

'CHAPTEK'711.0
'THERMO-MAGNETIC'1511.0

'MOTORS AND PYRO-MAGNETIC GENERATORS.'3641.0

That is the whole difference between 4 and 5. The default index reports 4 occurrences, on printed pp. 6, 429 twice and 496. The kept index reports 5, adding the chapter title on printed p. 424.

Neither number is wrong. Each is true of the text it was taken from. What this series does with that is stated once and followed everywhere: a count names its index, and a claim about the book uses the wider index, because the claim is about the book and not about a search tool. The free energy article prints 5 for the same reason and says the same thing in its own method paragraph.

What a Zero Does and Does Not Prove

A zero from this method has a scope, and the scope is the honest part of it.

It covers one text: the 1894 first edition, as its text layer reaches this machine. It does not cover a later printing, a different edition, a lecture transcript, or anything Tesla wrote after this volume. It does not cover an idea the book paraphrases without naming: the volume discusses energy, storage and loss constantly, and 'energy' and 'generator' are among its common vocabulary, so the absence of a two-word phrase is not the absence of a subject.

It also does not settle what Tesla meant anywhere else. The claim this site makes is narrow and it survives the search: a sentence circulated as his promise of free energy is printed in a book that never uses the phrase, and the one machine the book describes under a name containing 'magnetic generator' has a fire under it. Both halves of that, with the chapter, the footnotes and the question of who is writing in each passage, are on Tesla on Free Energy: What He Actually Said.

What would change these numbers, and by how much:

  • a different text layer. This one misreads folios on 35 pages and splits a chapter title into

four fragments. A better layer would not move the zeros for 'free energy', which are absences of a two-word sequence, but it could move the substring totals for hyphenated compounds

  • a looser adjacency rule. Counting 'free' and 'energy' within a few words of each other returns

non-zero results and answers a different question. This page counts the phrase, and says so

  • a different index. 4 or 5, as above

The same method on the same file, applied to a different phrase, is worked through in the article on the cold flame Tesla held in his hand, which whole-word searches 'cold flame' and 'cold fire', gets 0 for both, and then reports the words the book does use. The engravings from this scan are catalogued page by page at Tesla 1894 Plates.

Frequently Asked Questions

Does the 1894 Book Contain the Phrase Free Energy?

Not in our copy. 'free energy' returns 0 occurrences, whole-word and as a substring, in the text layer of a scan of the 1894 first edition, and so does 'free-energy'. The stem 'free energ' also returns 0, so a line-end hyphenation or a broken word would not hide a hit either. The two words on their own are common in the volume: 'free' appears 97 times on 73 printed pages and 'energy' 243 times on 119. The words are there. The phrase is not.

Does a Count of Zero Prove Tesla Never Said It?

No, and this page does not claim that. A zero here is a statement about one text: the 1894 first edition, edited by Thomas Commerford Martin, as its text layer reaches our machine. It says nothing about a later printing, a different edition, a lecture transcript, or anything Tesla wrote after 1894. What the zero does carry is a scope: the claim that this book says 'free energy' is refuted by this search, and the claim that Tesla 'believed in free energy' is untouched by it either way.

Why Do Two Runs of the Same Command Give Four and Five?

Because the default index drops running heads, bare page numbers and short all-capital display lines before it searches, and one of the five occurrences is a chapter title set in display type. Run with --keep-furniture the count is 5, on printed pp. 6, 424, 429 twice and 496. Run with the default index the chapter title on printed p. 424 is gone and the count is 4. Both numbers are true of the text each was taken from, which is why every count on this page names its index.
